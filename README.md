# 📚 企业智能 HR & IT 知识库问答系统 (Enterprise RAG Assistant)

一个面向企业内部员工（HR & IT 部门）的智能问答系统。支持上传企业制度文档，基于 **RAG（检索增强生成）** 流程实现精准答疑，并配备独立的知识库管理面板。

## 🔗 在线体验
👉 **[点击这里直接体验项目](http://121.41.178.89:8001)**

## ✨ 核心功能
- **现代化中后台界面**：使用 Vue3 搭建，支持多工作台切换、文档拖拽上传及丝滑的对话交互。
- **RAG 检索增强**：使用 LangChain 提取并切分长文档，存入 ChromaDB 向量数据库；基于语义相似度精准检索上下文。
- **防 AI 幻觉机制**：引入相似度阈值判断，若知识库中无匹配内容，系统将拒绝胡编乱造，提示用户暂无依据。

## 🛠️ 技术栈
- **前端**: Vue3 / Element Plus
- **后端**: Python / FastAPI / LangChain / ChromaDB
- **部署**: Docker / 阿里云 ECS
